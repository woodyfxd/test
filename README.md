# 🐾 ZooHotel CRM — CRM-система для гостиницы для животных и передержки

Полнофункциональная веб-CRM система, разработанная специально под бизнес-процессы зоогостиниц, передержек и кинологических отелей.

---

## 🚀 Быстрый запуск

Сервер запущен и доступен в браузере:
👉 **[http://localhost:5000](http://localhost:5000)**

### Команды запуска вручную:
```bash
# Запуск единого сервера (Бэкенд + Фронтенд на порту 5000):
cd backend
node server.js

# Режим разработки с горячей перезагрузкой (Vite на порту 3000):
cd frontend
npm run dev
```

## 🧩 Реализованный функционал

### 1. 📅 Шахматка номеров и календарь бронирований
* Наглядная интерактивная матрица номеров (Кошачий Люкс, Кошачий Стандарт, Собачий Премиум с видеонаблюдением, Собачий вольер с лужайкой, Медицинский карантин).
* Автоматический расчет количества суток, стоимости проживания и дополнительных услуг (груминг, занятия с кинологом, трансфер).
* Быстрые действия: **«Заселить гостя»** и **«Оформить выезд»**.
* При заселении автоматически формируются задачи осмотра врачу и кормления зооняне, а клиенту в WhatsApp уходит приветственное сообщение!
* При выселении номер автоматически переводится в статус *«Санитарная уборка»* и ставится задача дезинфекции.

### 2. 🐶 Реестр и медицинские карточки питомцев
* Учет вида (собака, кошка), породы, пола, возраста, номера микрочипа/клейма.
* Подробный рацион кормления с автоматическим выделением аллергий (например, *«Аллергия на курицу!»*).
* График приема медикаментов и витаминов.
* Сроки действия вакцин и обработок от паразитов.
* Индивидуальные заключения ветеринара, кинолога и фелинолога.

### 3. 💬 WhatsApp Бизнес-Центр (Приём и отправка)
* Полноценный интерфейс чата в стиле WhatsApp Web.
* Отправка текстовых сообщений и фотоотчетов владельцам.
* Кнопка **«Симуляция входящего сообщения»** — позволяет протестировать прием реального запроса от клиента прямо в интерфейсе с моментальным звуковым и визуальным уведомлением!
* Поддержка подключения внешних шлюзов (Green API, WPPConnect, WhatsApp Cloud API) через встроенный вебхук:
  `POST /api/whatsapp/webhook`

### 4. ⚡ Автоматические сервисные триггеры
* Автосообщения при создании бронирования с реквизитами и датами.
* Подтверждение бронирования с напоминанием взять ветпаспорт.
* Приветствие при заселении питомца.
* Напоминание за 24 часа до заезда.
* Вечерний отчет о самочувствии питомца.
* Редактор шаблонов с переменными `{{clientName}}`, `{{petName}}`, `{{roomName}}`, `{{startDate}}`, `{{endDate}}`, `{{totalAmount}}`.

### 5. ⏰ Напоминания и чек-листы для персонала
* Фильтрация задач по ролям: Зооняня, Кинолог, Фелинолог, Ветеринар.
* Фиксация точного времени напоминания (например, *08:00 кормление*, *13:00 дача таблетки*, *14:00 тренировка*).
* Функция **«Отметить выполнение с отправкой отчета в WhatsApp»** — при отметке задачи владельцу мгновенно отправляется отчет в чат!

### 6. 🔔 Системные уведомления на Компьютер и Телефон
* **На компьютер (Windows / macOS / Linux):** всплывающие системные уведомления в правом нижнем углу экрана через Web Notifications API. Работают даже когда вкладка браузера свернута!
* **На телефон (Android / iOS):** Progressive Web App (PWA) манифест и Service Worker (`sw.js`). При открытии сайта со смартфона и добавлении на главный экран приложение присылает уведомления на экран блокировки с вибрацией.
* **Аудио-сигнал:** встроенный колокольный звуковой сигнал через Web Audio API, слышимый в помещении при наступлении времени задачи или получении сообщения.
* **Telegram-бот дежурной смены:** моментальное дублирование напоминаний в закрытую Telegram-группу сотрудников или личный чат.
* **Кнопка «Оповещения»** в шапке сайта: позволяет в 1 клик проверить разрешения браузера, настроить каналы и протестировать звук + всплывающий баннер.

## 🛠 Архитектура решения

* **Frontend**: React 19, Tailwind CSS v4, Lucide React, Socket.IO Client, Service Worker PWA, Web Audio API, Vite.
* **Backend**: Node.js, Express, Socket.IO (реактивные WebSockets для сообщений и напоминаний в реальном времени).
* **База данных**: Автономное JSON-хранилище с поддержкой транзакций и предварительным заполнением реалистичными данными.
